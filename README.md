# AI-Powered Natural Language to SQL Query Generator
SQLify AI is a smart, developer-friendly application that converts natural language into valid SQL queries using advanced Large Language Models (LLMs). It helps data analysts, developers, and non-technical users quickly generate queries without manual SQL writing — making database interaction more intuitive, faster, and accessible.

# 🎯 Project Objective
To simplify SQL query generation by enabling users to ask questions in plain English and receive optimized SQL statements instantly, reducing development time and lowering the learning curve for working with databases.

# ✨ Key Features
🗣️ Natural Language Input – Type your question like:
“Show all users who registered in the last 30 days”

🧠 LLM-Powered SQL Generator – Generates syntactically correct SQL queries using OpenAI, GROQ, or Hugging Face models.

⚡ Fast Inference – Uses GROQ (Mixtral) for ultra-low-latency query responses.

📊 Query Execution (Optional) – Run SQL queries directly on a connected SQLite database and preview results.

📝 Editable Output – Users can fine-tune or copy generated SQL for use in their own tools.

🧩 Step-by-Step Reasoning – Get a breakdown of how the AI interpreted the input and formed the query.

# 🛠️ Tech Stack

Component	Technology
🧠 LLM Engine	OpenAI GPT-4, GROQ (Mixtral), Hugging Face
🔄 Query Framework	LangChain, LangGraph
💻 UI Framework	Streamlit
🗃️ Database	SQLite (Test DB)
